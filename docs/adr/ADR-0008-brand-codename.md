# ADR-0008 — "NEST" is a working codename pending brand clearance

Date: 2026-02-11 · Status: Accepted (risk tracked) · Reviewer: Principal Engineer, Solution Manager

## Context
A Kenyan fintech ("nesti") operates in rent payments. Brand investment before clearance risks rename cost.

## Decision
Treat "NEST" as a codename. Brand clearance (trademark search, domain, app-store name) is a Phase-2 blocking issue before any public marketing. The README and product copy use the name with this disclaimer.

## Consequences
- ⚠️ Possible rename; all user-facing strings live in i18n dictionaries and design tokens (single-point rename possible in hours).
